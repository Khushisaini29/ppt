03 · REQUEST AND RESPONSE

How the Internet Works

Opening a website follows a clear request-and-response path.

1Enter a web addressExample: www.example.com
2DNS lookupFinds the IP address
3HTTP/HTTPS requestTravels across the network
4Server responseReturns web resources
5Browser rendersDisplays the webpage
DNS finds the IP address, HTTP/HTTPS transfers web resources, and the browser displays the webpage.

05 · CLEAR THE CONFUSION

Browser vs Search Engine

Browser

Software application installed on or available through a device.

  • Opens and interacts with websites
  • Renders web pages and media
  • Examples: Chrome, Firefox, Safari, Edge
VS

Search engine

Online service that helps people discover information and websites.

  • Uses an index to find relevant results
  • Runs inside a browser
  • Examples: Google Search, Bing, DuckDuckGo
Google Chrome is a browser; Google Search is a search engine.

07 · THE SERVICE PROVIDER

The Server

A hardware system or software program that processes client requests and provides data, resources, or services over a network.

Web serverDelivers website resources. Apache, Nginx.
Database serverStores and retrieves data. MySQL, PostgreSQL, MongoDB.
Application serverRuns application logic and business rules.
File serverStores and shares files and backups.
Mail serverHandles email sending, receiving, and storage.
A server receives requests, processes them, and returns appropriate responses.
